# patchedwatch-datos

Datos que muestra la sección «Compruébalo ahora» de PatchedWatch by Cogniria: las vulnerabilidades críticas de los últimos 12 meses de una selección de tecnologías y la versión que hace falta en cada rama.

- `tecnologias.json` se genera y se publica de forma automática varias veces al día. Nadie lo edita a mano.
- Sale de los registros oficiales de vulnerabilidades y de la lista de fallos explotados en ataques reales.
- Solo incluye fallos críticos explotables a distancia, con el mismo criterio que los avisos del servicio.
- Es una muestra: el servicio vigila cualquier producto que declare cada cliente.

Este repositorio no acepta cambios externos.
